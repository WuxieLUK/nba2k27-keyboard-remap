NBA 2K27 键盘自定义 v5.0 — 直接按键绑定
===========================================

这版不再使用下拉框。

改键方法
--------
1. 运行 NBA2K27_Keyboard_GUI_v5.exe
2. 点击你要修改的操作右侧键位框
3. 键位框显示“请按一个键…”
4. 直接按键盘上的目标键
5. 点击“保存并应用”

例如：
点击“投篮 / 假投”的 NUMPAD5
→ 按 J
→ 界面变成 J
→ 保存并应用
以后按 J 就向游戏发送原来的小键盘 5。

支持直接识别
------------
A-Z、0-9
方向键 ↑ ↓ ← →
Space、Tab、Enter
左/右 Shift、Ctrl、Alt
Page Up / Page Down
Home / End / Insert / Delete
小键盘 0-9、+、-、*、/、Enter
F1-F24（F8/F9/F10 除外）
常用符号键：- = [ ] \ ; ' , . / `

注意
----
F8 / F9 / F10 是后台映射器的保留键，不能拿来绑定游戏操作。
目前每个操作绑定一个单键，不做 Ctrl+J 这类组合键。
高吊 / 空接仍保持游戏原操作：
单击 LOB_ALLEY 的自定义键 = 高吊
快速双击 = 空接

如果要在记事本测试：
取消“仅在 NBA 2K27 前台生效”
→ 保存并应用
→ 在记事本测试
测试后重新勾选并保存应用。

建议开启 Num Lock 后使用小键盘绑定，以保证游戏和 Windows 对小键盘键位的识别一致。
